# Luma Music Roadmap

*Your music. The experience it deserves.*

This page outlines the next areas of work for Luma Music. These are **plans, not released features**, and priorities may change as development and testing continue.

## What's next

### Documentation & getting started

- **Feature guides** — Dedicated pages explaining how selected Luma Music features work, including requirements, supported data formats, and limitations.
- **Server setup guide** — Step-by-step guidance for setting up and configuring a compatible personal music server, with a focus on Navidrome and connecting it to Luma Music.
- **Clearer installation guidance** — Make the existing IPA sideloading and first-time connection steps easier to follow.

### Platform roadmap

- **macOS — Coming next year (2027)** — A dedicated macOS version is planned. It is not currently available and there is no macOS release or installer yet.

## Current availability

Luma Music is currently distributed as an **IPA preview for iPhone and iPad**. A compatible, separately hosted music server is required.
