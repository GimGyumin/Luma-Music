## Common questions.

### Where can I install Luma?

Luma currently offers **iPhone and iPad IPA previews** via [GitHub Releases](https://github.com/GimGyumin/Luma-Music/releases). You'll need a compatible sideloading method. No TestFlight or App Store version is currently available.

### Does Luma include music?

No. You need a compatible self-hosted music server and your own library. Luma is the player that connects to it.

### Why don't all songs have lyrics?

The server or a supported lyric source must supply them. **TTML word animation requires timing information**, and **pronunciation requires a compatible pronunciation layer**.

### Why doesn't an album have immersive artwork?

Some album covers don't support the immersive presentation. The standard album view may still be available.

### Is there a Mac app?

A dedicated macOS version is planned for **2027**; it isn't released yet.

## Report an issue, safely.

Include the steps to reproduce the problem, your Luma build, device and OS version, server type, and screenshots or logs if available.

**Before posting:** Remove passwords, tokens, private server URLs, account identifiers, and other sensitive information from screenshots and logs.
