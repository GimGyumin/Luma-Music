# About Offline Downloads

Downloads store server tracks on the device so they play without a network.

## Quality

- Choose download quality in **Settings → Music → Audio Quality**.
- Original stores the server file without conversion.
- Existing downloads are not automatically replaced when you change quality.

## Storage

- Review and clean up in **Settings → Downloads → Downloaded Music**.
- Playback cache and downloads are separate; clearing cache keeps downloads.
- Check the preserve option when signing out or removing a server.

## Offline playback

Downloaded tracks play in airplane mode. If the server becomes unreachable, the last playback position is still kept on the device.
