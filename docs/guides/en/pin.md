# About Pin

Pin keeps frequently used albums, artists, and playlists close on Home and in the pinned widget.

## How to use it

1. Open the menu for an album, artist, or playlist.
2. Choose **Pin**.
3. Open it from the pinned area on Home or the pinned widget.

## Notes

- Pins are stored per server account.
- Switching servers shows only that server's pins.
- Unpinning never deletes the original album or playlist.
- Signing out clears local pins; pin them again after signing in.
