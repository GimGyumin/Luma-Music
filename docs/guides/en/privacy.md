# About Privacy

Luma Music exchanges only the data needed for playback with your server.

## Stored on this device

- Server address and account password are stored in the Keychain.
- Downloads, playback cache, and lyric cache live in app data.
- Listening history and Replay statistics are aggregated on the device.

## Sent outside the device

- Guides and feedback use only the Luma Music GitHub repository.
- Lyrics are sent to the translation provider only when OpenAI translation is enabled.
- Diagnostics are never uploaded automatically. Review any log before attaching it to feedback.
- Server passwords, API keys, tokens, and private URLs are never sent to GitHub.

## Cleanup

Manage cache and downloads in **Settings → Downloads**. Deleting the app also deletes its local data.
