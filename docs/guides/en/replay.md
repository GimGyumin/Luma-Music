# About Replay

Replay uses listening activity on this device to show Recently Played, heavy rotation, and revisit suggestions.

## Data

- Listening activity is aggregated on the device.
- Server submission runs only when you enable it.
- Turning history off excludes future playback from statistics.

## What it powers

- **Recently Played**: reopen recent albums and tracks.
- **Heavy Rotation**: music you return to often.
- **Get Up! / New Music**: suggestions based on history and library genres.

Recommendations may arrive later depending on the network and server. Existing lists stay in place while new data loads.
