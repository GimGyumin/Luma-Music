# About Volume Leveling

Volume Leveling (ReplayGain) reduces loudness differences between tracks and albums. It applies gain during playback; the original file is never modified.

## Modes

- **Track**: match loudness per song. Best for shuffle.
- **Album**: preserve the intended loudness relationship inside an album.
- **Prevent clipping**: limit positive gain so peaks are not cut off.

## Notes

- Automatic values require ReplayGain tags from your server.
- Tracks without tags play without leveling.
- Audio quality and source data are unchanged.

Find it in **Settings → Music → Volume Leveling**.
