# Using Siri and Shortcuts

Luma can open songs, albums, artists, and playlists from Siri and the Shortcuts app.

## Requirements

- An OpenSubsonic server must be signed in.
- The initial music-library index must be ready.
- Use Luma at least once so iOS can learn the app for Siri.

## Examples

- “Hey Siri, open Smooth Criminal in Luma.”
- Add **Open Song**, **Open Album**, or **Open Playlist** actions in Shortcuts.

## Notes

Spoken search terms may be sent to Apple services. Server passwords and tokens are not included in Siri or Shortcut actions. Some items may be unavailable until library indexing finishes.
