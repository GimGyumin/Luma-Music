# 무손실 오디오에 관하여

Luma Music은 서버가 제공하는 원본 파일을 손실 압축으로 변환하지 않고 재생합니다. 선택한 품질과 서버 파일에 따라 FLAC, ALAC, 고해상도 PCM이 그대로 출력됩니다.

## 확인할 점

- 무손실 파일은 용량이 커서 첫 소리까지 시간이 더 걸릴 수 있습니다.
- 블루투스 이어폰이나 일부 출력 장치는 원본을 다시 압축할 수 있습니다.
- 서버가 변환 스트림을 제공하면 현재 재생 배지에 실제 전달 형식이 표시됩니다.
- 다운로드한 원본은 네트워크 없이도 원음 그대로 재생됩니다.

## 시작이 느릴 때

1. Wi-Fi에서 다시 시도합니다.
2. 서버의 업로드 속도와 동시 접속 수를 확인합니다.
3. 오디오 품질을 자동으로 두고 네트워크에 맞게 조정되는지 확인합니다.

무손실을 켠다는 이유만으로 손실 원본이 무손실로 바뀌지는 않습니다.
