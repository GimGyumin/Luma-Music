# 가사 동기화에 관하여

Luma는 서버가 제공하는 가사와 외부 가사 소스를 이용해 재생 위치에 맞춰 가사를 표시합니다.

## 지원 형식

- 일반 LRC
- 단어별 타이밍이 있는 LRC/TTML
- OpenSubsonic `songLyrics` v2 (번역·발음 포함)
- Apple Music 스타일 TTML

## 표시 방식

- 현재 줄은 재생 위치에 맞춰 강조됩니다.
- 단어별 타이밍이 있으면 단어가 진행되는 만큼 하이라이트됩니다.
- 빠른 구절에서는 줄 간격에 맞춰 강조 애니메이션 시간이 짧아집니다.
- 사용자가 직접 스크롤하면 자동 스크롤이 잠시 멈춥니다.

## 문제 해결

- 가사가 없으면 서버의 가사 설정과 곡 메타데이터를 확인하세요.
- 번역이 보이지 않으면 **설정 → 가사 및 번역**에서 번역 엔진과 언어를 확인하세요.
- Seek 후에는 현재 위치의 줄로 즉시 이동합니다.
