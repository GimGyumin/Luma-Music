# 오프라인 다운로드에 관하여

다운로드는 서버의 곡을 기기에 저장해 네트워크 없이 재생할 수 있게 합니다.

## 품질

- 다운로드 품질은 **설정 → 음악 → 오디오 품질**에서 정합니다.
- 원본을 선택하면 서버가 제공하는 파일을 변환 없이 저장합니다.
- 이미 받은 파일은 품질 설정을 바꿔도 자동으로 다시 받지 않습니다.

## 저장 공간

- **설정 → 다운로드 → 다운로드한 음악**에서 용량을 확인하고 정리할 수 있습니다.
- 재생 캐시와 다운로드는 별개입니다. 캐시를 지워도 다운로드는 유지됩니다.
- 로그아웃하거나 서버를 삭제할 때 다운로드 보존 여부를 확인하세요.

## 오프라인 재생

다운로드가 완료된 곡은 비행기 모드에서도 재생됩니다. 서버 연결이 끊겨도 마지막 재생 위치는 기기에 저장됩니다.
