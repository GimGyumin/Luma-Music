# Pin 기능에 관하여

Pin은 자주 여는 앨범, 아티스트, 재생 목록을 홈이나 위젯에서 빠르게 접근하도록 고정합니다.

## 사용 방법

1. 앨범·아티스트·재생 목록의 메뉴를 엽니다.
2. **고정**을 선택합니다.
3. 홈의 고정 영역이나 고정 위젯에서 바로 엽니다.

## 참고

- 고정 항목은 서버 계정별로 저장됩니다.
- 다른 서버로 전환하면 그 서버의 고정 항목만 표시됩니다.
- 고정을 해제해도 원본 앨범이나 재생 목록은 삭제되지 않습니다.
- 로그아웃 시 로컬 고정 데이터가 정리되며, 재로그인 후 다시 고정할 수 있습니다.
