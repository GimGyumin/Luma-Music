# 개인화 추천에 관하여

나의 플레이리스트 탭에는 사용자의 청취 기록을 바탕으로 만든 Luma 추천이 서버 플레이리스트와 별도 섹션으로 표시됩니다.

## 다시 듣기

- 최근 120일 안에 서로 다른 트랙을 2개 이상 들은 앨범만 후보가 됩니다.
- 한 곡만 반복한 경우는 앨범 전체를 감상한 것으로 보지 않습니다.
- 완료한 트랙이 있거나 충분히 오래 들은 앨범을 최근 순서로 보여줍니다.
- 기록이 부족하면 가짜 앨범을 만들지 않고 섹션을 숨깁니다.
- 앨범을 선택하면 해당 앨범 상세로 이동합니다.

## Luma 믹스

Get Up!, Heavy Rotation, 나의 필수곡, 신규 음악 등은 서버 플레이리스트가 아니라 기기에서 계산한 믹스입니다. 서버 정렬과 무관하게 사용자 플레이리스트보다 위에 표시되며, 데이터가 없으면 빈 항목은 숨깁니다.

추천은 서버에 추가 요청을 보내지 않고 기존 청취 기록과 라이브러리 메타데이터를 재사용합니다.
