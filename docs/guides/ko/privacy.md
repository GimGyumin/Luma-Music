# 개인정보 보호에 관하여

Luma Music은 재생에 필요한 데이터만 서버와 주고받습니다.

## 기기에 남는 정보

- 서버 주소와 계정 비밀번호는 Keychain에 저장됩니다.
- 다운로드 파일, 재생 캐시, 가사 캐시는 앱 데이터에 저장됩니다.
- 듣기 기록과 Replay 통계는 기기에서 집계됩니다.

## 외부로 나가는 정보

- 가이드 문서와 피드백은 Luma Music GitHub 저장소에서만 불러오거나 엽니다.
- OpenAI 번역을 켠 경우에만 가사 텍스트가 번역 제공자에게 전송됩니다.
- 진단 로그는 자동으로 전송되지 않습니다. 피드백에 첨부하려면 사용자가 직접 내용을 검토해야 합니다.
- 서버 비밀번호, API 키, 토큰, 비공개 URL은 GitHub로 전송되지 않습니다.

## 정리

**설정 → 다운로드**에서 캐시와 다운로드를 관리할 수 있습니다. 앱을 삭제하면 기기 내 데이터가 함께 삭제됩니다.
