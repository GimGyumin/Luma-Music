# Replay 기능에 관하여

Replay는 기기에서 들은 음악을 바탕으로 최근 재생, 자주 들은 음악, 다시 듣기 추천을 보여줍니다.

## 데이터

- 듣기 기록은 기기에서 집계됩니다.
- 서버에 기록을 보내는 기능은 사용자가 켠 경우에만 동작합니다.
- 기록을 끄면 이후 재생이 통계에 반영되지 않습니다.

## 활용

- **최근 재생**: 최근에 들은 앨범과 곡을 빠르게 다시 엽니다.
- **Heavy Rotation**: 반복해서 들은 음악을 모읍니다.
- **Get Up! / New Music**: 듣기 기록과 라이브러리 장르를 이용해 제안합니다.

추천 데이터는 네트워크와 서버 상태에 따라 늦게 표시될 수 있으며, 로딩 중에도 기존 목록은 유지됩니다.
