# 볼륨 평준화에 관하여

볼륨 평준화(ReplayGain)는 앨범이나 곡의 재생 음량 차이를 줄입니다. 원본 파일은 수정하지 않고 재생 시 게인만 조정합니다.

## 모드

- **트랙**: 곡마다 음량을 맞춥니다. 셔플 재생에 적합합니다.
- **앨범**: 같은 앨범 안의 곡 간 음량 관계를 유지합니다.
- **클리핑 방지**: 게인을 올릴 때 파형이 잘리지 않도록 제한합니다.

## 참고

- 서버가 ReplayGain 태그를 제공해야 자동 값이 적용됩니다.
- 값이 없는 곡은 평준화 없이 재생됩니다.
- 음질이나 원본 데이터는 변경되지 않습니다.

설정은 **설정 → 음악 → 볼륨 평준화**에서 변경할 수 있습니다.
