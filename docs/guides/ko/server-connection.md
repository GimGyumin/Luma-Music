# 서버 연결 방법

Luma Music은 OpenSubsonic 호환 서버에 연결해 음악을 재생합니다.

## 준비물

- 서버 주소(예: `https://music.example.com`)
- 사용자 이름과 비밀번호
- 서버에서 OpenSubsonic API가 활성화되어 있어야 함

## 연결

1. **설정 → 계정 → 서버**에서 서버 주소를 입력합니다.
2. 계정 정보를 입력하고 연결을 확인합니다.
3. 홈 화면에서 앨범과 재생 목록이 나타나면 연결된 것입니다.

## 연결 문제

- 주소에 `/rest`를 붙이지 마세요. Luma가 API 경로를 처리합니다.
- 자체 서명 인증서를 사용하는 서버는 iOS 신뢰 설정이 필요할 수 있습니다.
- VPN이나 방화벽이 API 요청을 막지 않는지 확인합니다.
- 서버 비밀번호와 토큰은 기기 Keychain에 저장되며 GitHub로 전송되지 않습니다.
