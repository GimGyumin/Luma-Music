# 스트리밍 캐시에 관하여

스트리밍 캐시는 최근 재생한 곡의 데이터를 기기에 보관해 다음 재생을 더 빠르게 시작합니다.

## 다운로드와의 차이

- **캐시**: 재생을 돕기 위한 임시 데이터입니다. 저장 공간이 부족하면 정리될 수 있습니다.
- **다운로드**: 사용자가 명시적으로 저장한 파일이며, 캐시 정리와 무관하게 유지됩니다.

## 자동 캐시

Luma는 재생이 안정된 뒤에만 캐시 전송을 시작합니다. 재생 중 버퍼가 부족해지면 캐시 전송을 취소해 스트림에 대역폭을 우선 배정합니다.

## 관리

**설정 → 다운로드 → 캐시**에서 현재 사용량을 확인하고 비울 수 있습니다. 캐시를 비워도 다운로드와 재생 목록은 삭제되지 않습니다.
