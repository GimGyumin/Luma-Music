# Luma Music 1.0 RC1

**First public release candidate · iPhone and iPad IPA preview**

*Your music. The experience it deserves.*

Luma Music is an independent, open-source music player for your own Navidrome, OpenSubsonic-compatible, or supported Jellyfin library. RC1 introduces an artwork-focused, Apple Music-inspired interface, rich synchronized lyrics, and high-quality playback.

## Download and installation

**[Download the RC1 IPA](https://github.com/GimGyumin/Luma-Music/releases/download/v1.0.0-rc1/Luma-Music-1.0-RC1.ipa)**

1. Download the `Luma-Music-1.0-RC1.ipa` file.
2. Use a compatible IPA signing and sideloading method (for example, SideStore or AltStore) to install it on a supported iPhone or iPad.
3. Open Luma Music and connect to your own compatible music server.

**This is RC1, not the final 1.0 release or the upcoming post-rebrand build.** There is currently no App Store or TestFlight distribution.

## What's included

- **Native, artwork-focused listening** with immersive visuals when compatible artwork and device support them.
- **Synchronized lyrics** with line-level or word-level highlighting when the server or a supported lyric provider supplies compatible data.
- **Optional lyric translation** through supported Apple or OpenAI features; **pronunciation display only for lyrics that include compatible pronunciation data**.
- **Gapless playback, lossless streaming, crossfade, and ReplayGain** when supported by the source and playback configuration.
- **Offline downloads, search, library browsing, caching, and network recovery**.
- **System integration** with supported Siri/Shortcuts actions, Spotlight, widgets, and playback controls.

## Important notes

- Luma requires a separately configured, compatible personal music server. No commercial music catalog is included.
- Some immersive album presentations may not work for every cover.
- Lyrics require available lyric data; word-timed animation requires compatible timings. Pronunciation cannot be generated for every song.
- Optional integrations may require suitable system capabilities and signing entitlements.
- This is a release candidate: bugs and regressions are possible.
