# Luma Music 1.0 RC3 — Preview

**Third release candidate · iPhone and iPad IPA preview**

*Your music. The experience it deserves.*

RC3 brings a redesigned listening experience, a new Lyricify-powered artwork background, improved synchronized lyrics, refined library navigation, and extensive reliability work. It is a substantial update from RC2, not just a maintenance release.

> **Release status:** Draft. RC3 IPA, build number, and public release URL are not yet finalized. RC2 remains the latest published release.

## Download and installation

The RC3 IPA download will appear here after final verification and signing. Install the signed IPA with a compatible sideloading method (such as SideStore or AltStore), then connect to your own compatible music server.

This is a **pre-release**, not stable 1.0. There is currently no App Store or TestFlight distribution.

## What's new in RC3

### An immersive new player

The Now Playing experience has been substantially refined, with a wider, artwork-focused player layout, redesigned immersive presentation, and more consistent transitions between player, lyrics, and queue. A new **Lyricify** background pipeline uses artwork and audio-responsive rendering to bring the listening screen to life.

### Lyrics that move with the music

Adaptive lyric scrolling and improved word-timed presentation make synchronized lyrics easier to follow when compatible timing data is available. RC3 adds an **English-to-Korean pronunciation fallback** using CMUdict for supported English words, alongside refinements to lyric display and translation. Pronunciation is approximate and coverage varies by word.

### A more polished library and iPad experience

Home, albums, artists, songs, and playlists have received navigation and layout refinements. The iPad sidebar adds updated profile and artwork presentation. RC3 also introduces refreshed welcome and release-introduction screens.

### Playback and responsiveness refinements

Changes across playback transitions, gapless behavior, audio session handling, artwork caching, network probing, and library indexing aim to improve day-to-day reliability. Actual battery and performance results depend on device and usage.

### Stability and data retention

Recent testing by the developer has not reproduced previously observed resets affecting Replay data, queue history, or search history. This is an encouraging result, but broader update, relaunch, and device testing is still required.

## More improvements

- **New rendering pipeline:** Lyricify background mesh, GPU renderer, bass analyzer, and Metal shaders replace older artwork-rendering components.
- **Lyrics:** Adaptive scroll motion and trajectory, pronunciation fallback, translation and display updates, and expanded localization.
- **Library:** Refinements to Home discovery, song/album/artist/playlist views, iPad sidebar, and artwork storage.
- **Playback:** Updates to gapless transitions, playback engine callbacks, audio sessions, and media resolution.
- **Testing and CI:** Additional automated tests; iOS simulator build, unit tests, authenticated listening journey, and unsigned archive verification workflows.
- **Platforms:** The iOS/iPadOS project no longer builds macOS. A separate Luma-Mac project is planned.

## Important notes

- A compatible personal Navidrome, OpenSubsonic, or supported Jellyfin server is required; Luma does not provide a music catalog.
- Lyric timing, pronunciation, translation, artwork effects, and lossless audio depend on the source, device, and enabled integrations.
- Siri App Intents currently have a CI compilation failure under the selected Xcode 27 environment. RC3 must not be released until the build is verified.
- Increase `CURRENT_PROJECT_VERSION` from 1031 to **1032 or later** for RC3 and verify the signed IPA on real devices.
- The RC2-era iPad compatibility advisory remains relevant until RC3's iPad fixes are verified.
